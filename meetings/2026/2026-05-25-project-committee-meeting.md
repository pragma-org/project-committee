## Discussions
- Tapdano: Code base looks good but questions if we can adequatly judge the NFC segment especially security related. Question of how adopted the solution is in the ecosystem but overall positive to a long standing project in the ecosystem.
- Cardano-init: Is this similar to cardano-up (or txpipes supernode for that matter) or more wider application, seems to be more wider given potential inclusion of meshDK or similar. Discussion if it would be node-neutral so we dont end up in a scenario where all new devs use same node version potentially skewing overal network if it gained big popularity and as a principle.
- ContractsLibrary: Seems a need for this, one of the members of committee had for example experienced serialization issues between cardano-cli and pycardano in the past, so work on a standard meeting new developers and with consistancy seems important.
- IOG application: Can a project with no current code base but where Pragma could help work on the standards applied to that codebase fit under Pragma? As a reputable developer in the ecosystem and with current low application numbers would it make sense to do another round of applications or accept the projects if we think it makes sense at an early stage where we can influene its direction more.
